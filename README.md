HWWHP Shimeji Pack (v1.0.0)

Welcome to the desktop Shimeji mascot pack based on the psychological horror Roblox game "HWWHP" (Happy World With Happy People)! 
Keep your favorite characters walking, crawling, and sitting right on your screen :D

For now, only one character (Thomas) is available, but the others will be added according to this list:

- [x] Thomas
- [ ] Soren
- [ ] Andreas
- [ ] Jennifer
- [ ] Cain

ALL CHARACTER MODELS WILL BE BASED ON THEIR REAL-WORLD DESIGN, NOT ON HALLUCINATIONS!!!


Installation & Usage guide:

MAKE SURE YOU HAVE INSTALLED JAVA!

1. Go to the "Releases" tab on the right side of this page and download the latest .zip archive.
2. Extract the archive on your PC.
3. Run the main executable "Shimeji-ee.jar".
4. A character selection menu will appear; make sure that only Thomas is selected, as he is the only working character.
5. If the sound effects bother you, you can disable them: click the ^ icon on your taskbar, right-click the application icon (which looks like a computer), select "Allowed Behaviours," and uncheck the "Sound Effects" option.
6. Have fun!

Future character updates will be added into the "img/" directory. You can either download the full pack again or just replace the specific character folder.
